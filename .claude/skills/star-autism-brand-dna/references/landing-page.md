# STAR Autism Support — Landing Page Guide

For marketing pages, tool launch pages, and the main STAR tools hub.

---

## Section Order

1. **Nav** — Sticky, logo left, primary CTA right
2. **Hero** — Mission-led headline + subheadline + CTA + trust row
3. **Social proof bar** — Key stats (districts, educators, years)
4. **Tool cards / Value prop** — What STAR offers
5. **How it works** — 3-step flow
6. **Testimonials** — Real educator quotes
7. **Research credibility** — Dark blue section
8. **Secondary CTA** — Different angle from hero
9. **Footer**

---

## Hero

```
Layout:        Two-column desktop (text left, visual right), stacked mobile
Headline:      Max 8 words. Lead with student outcomes.
               ✓ "Every Student With Autism Deserves to Thrive"
               ✗ "The Leading ABA Curriculum Platform"
Subheadline:   2–3 sentences, max 40 words. Who + what + why it works.
CTA primary:   Amber — "Explore the Curriculum" / "Try Our AI Tools"
CTA secondary: Ghost — "Watch a Demo →"
Trust line:    Below CTAs, small: "Used in 2,500+ school districts"
Visual:        Warm classroom photo or illustrated tool preview screenshot
```

## Social Proof Bar

```
Background:    var(--color-surface-alt)
Layout:        3–4 stats centered, separated by subtle vertical dividers
Stats:         "2,500+ School Districts" | "25,000+ Educators" | "30+ Years of Research"
Typography:    Nunito 800 2rem for numbers, Open Sans 500 13px muted for labels
```

## Tool Cards (for tools hub landing page)

```
Grid:          3-column desktop, 2-column tablet, 1-column mobile
Card:          Icon (40px outline, --color-primary) + Name (Nunito 700 18px) +
               1-sentence description + [Open Tool →] amber ghost link
Hover:         --shadow-md + subtle lift
Label badge:   "New" or "Beta" pill in --color-cta-light if applicable
```

## Testimonials

```
Layout:        2–3 cards in a row, 1 card on mobile
Quote:         Italic, Open Sans 16px body
Attribute:     Name (600 weight) + Title, District
Left border:   4px solid var(--color-cta) — amber accent
Avatar:        40px circle if available, initials fallback
```

## Research / Credibility Section

```
Background:    var(--color-primary) — full-width dark blue
Text:          var(--color-text-inverse)
Headline:      "Grounded in 30+ Years of Applied Research"
Content:       2–3 short research callouts or certification badges
CTA:           Ghost white-border button — "Read the Research"
```

## Footer

```
Background:    var(--color-primary)
Layout:        4 columns: Logo+tagline | Product | Resources | Contact
Text:          White at 80% opacity for secondary links
Divider:       1px rgba(255,255,255,0.15) above copyright
```

---

## Typography on Landing Pages

```
H1:            Nunito 900, 3rem desktop / 2.25rem mobile, --color-primary
H2:            Nunito 800, 2rem desktop / 1.625rem mobile
H3:            Nunito 700, 1.25rem
Body:          Open Sans 400, 1rem, line-height 1.7
Eyebrow:       Open Sans 600, 0.75rem, uppercase, letter-spacing 0.08em, --color-primary-mid
               Used above section headlines: "EVIDENCE-BASED CURRICULUM"
```

## Spacing

```
Section padding:   80–100px vertical desktop, 48px mobile
Content max-width: 1200px centered
Text column width: max 680px for readability
```

## Mobile

```
Hero:          Stack text first, image below (or hide on smallest screens)
All columns:   → single column below 768px
CTA buttons:   Full width on mobile
Nav:           Hamburger → overlay drawer
Social proof:  2×2 grid on mobile
```
